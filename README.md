### On building with AI

My delivery is AI-assisted, and I invest in the guardrails that make that safe:
architectural boundaries enforced by linter, import-direction and file-size gates in CI,
type checks that fail the container build, and conformance suites that validate code
against the live database schema.

The principle I work to: *the system that is allowed to guess does the guessing; the
system that has to be right stays deterministic.*
